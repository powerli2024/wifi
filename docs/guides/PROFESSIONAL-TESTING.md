# 专业测试的填写与复测

状态：Active；适用0.6.0保留的专业链；[文档导航](../README.md)。

| 想回答的问题 | 选择/填写 | 判断所需前提 |
|---|---|---|
| 系统能否解析 | 系统DNS，填写目标域名 | 系统可能选择地址族并使用缓存；返回地址不是泄露判定 |
| 同一解析器UDP/TCP差异 | 原始DNS，数字服务器、端口53、同域名及A或AAAA | 两协议分别执行，不自动回退；保持域名/类型/目标一致 |
| 出口是否符合策略 | HTTPS出口，可信服务origin、预期来源IP、信任声明 | 服务实现/v1/echo契约；来源预期从独立事实取得，不从本次观察反推 |
| 普通网址卡在哪层 | 另进网站深度诊断，填写HTTPS网址 | 无需回显服务/预期出口；结果是访问观察 |

专业raw默认每项8秒、默认一次，显式复核最多两次且共享总预算；深度DNS四项每项4秒、各一次。原始UDP/TCP会发明文DNS，即使Private DNS已开启也不是同一协议实验。

修复前保存专业实测为基线，只改一项并记录；保存YAML副本后需手动导入客户端、检查覆盖设置，再按原计划复测。不同目标/类型、网络变化、取消或演示报告不能混成可比改善。深度报告尚未接入该基线。详细操作见[DNS修复](DNS-REPAIR.md)、[原始DNS](RAW-DNS.md)和[回显契约](../specs/ECHO-CONTRACT.md)。
