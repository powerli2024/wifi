## 交付变化

- 新增网站与网络深度诊断入口：ChatGPT预设/自定义HTTPS，自动网络画像、内置本机正常/超时/拒连实验、DNS/连接/TLS/HTTP/正文逐层证据和暂时失败一次复核。
- 扩展实验自动填当前网络DNS，一次选中后执行A/AAAA与UDP/TCP四项，减少输入；未执行/中止/部分成功不能显示四项完成。
- TLS证书与主机名正常校验，记录版本、密码套件、到期和HTTP协议；GET16KiB读取计数，响应正文不留存，3xx不自动跟随。原严格/v1/echo政策实验保留。
- 深度报告同时保存用户代理声明、前后系统画像与请求代理选择；默认脱敏，完整导出也省略网址路径、查询参数和正文。
- 修复旧HTTPS空闲超时被当作单次上限的问题；修复重试分歧/提前停止时详细建议与摘要矛盾。
- 新会话使用运行身份隔离旧取消/监测任务，导出用不复用的请求编号与冻结payload，防旧文件选择回调串新报告。只有已结束且可比的DNS实验生成协议建议。

## 本地验证

最终 **450 项通过，0 失败、0 跳过**：核心/独立对抗207，控制器51，Android框架模拟182，Python回环TLS fixture10。Lint为0错误、1条OldTargetApi提示（保留targetSdk35）。APK版本0.6.0/code6，v2签名验证通过，证书与0.5.0一致。已核对业务权限与有效Manifest，没有新增服务或导出诊断入口。

最终计数与交付哈希以 `verification/v0.6.0/verification-summary.json` 和 `dist/package-validation-0.6.0.json` 为准。验证包括核心/独立对抗用例、受控本机HTTPS、控制器假平台、Android框架模拟、Lint、APK元数据与签名。框架模拟运行API29/35，不是Android模拟器或API36设备实测。

网站测试使用本地受控HTTPS与测试专用信任配置，覆盖正常响应、未知CA、错主机名、过期/未生效证书、403、跳转、有界正文、慢滴流、复核、取消、阻塞DNS与工作槽交接。生产构造保持默认平台信任，测试CA和测试服务器库不打入APK。

初轮日志保留排错历史：修复OkHttp Dns接口构造和测试隐藏API调用的编译错误；一次正常网站测试曾返回ERROR且旧断言未输出细节，该次具体原因未获证实。随后增加完整失败诊断，并修复静态确认的工作槽交接竞态，加入500次连续交接回归。还修正JSON转义导致的测试比较方式和旧回环夹具双协议端口分配冲突；业务断言未放宽。Python检查改用已有、具备cryptography的运行环境，未修改全局Python。最终通过只证明所列本地条件，不把复跑成功当作原失败根因已复现。

## 资源、权限与尚待验证

业务权限保持INTERNET/ACCESS_NETWORK_STATE；不申请定位、电话、root、抓包VPN或安装CA。新增OkHttp4.12.0/Okio3.6.0，使用Android网络与TLS；没有外部解释器、遥测或后台轮询。依赖清单和许可随源码/APK保留。

系统DNS、文件提供者或系统调用可能不立即响应取消；结果预算与实际资源释放分开，旧工作未退出时保留占用而不无限开线程。新增网络监测是快照观察，不是逐包外层抓包。

尚未在用户手机验证新功能、厂商文件选择器、大字体/TalkBack、真实代理路径或客户端配置生效。原报告的API36蜂窝DNS成功只属于0.5.0，两份原JSON保持不变。未新增QUIC/WebRTC、强制地址族实验、DoH/DoT独立探针、网页登录或完整ChatGPT业务验证。下一步按本版真机指南实测。
