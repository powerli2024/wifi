## 交付变化

- 深度诊断使用顶端主要定位、DNS/连接/TLS/HTTP/正文五行摘要、默认折叠的详细证据；工具栏始终保留导出入口，报告动作放在长证据之前。HTTP 代理解析说明不覆盖实际网站故障摘要。
- 增加独立深度基线：完整运行可保存，即使得到确定的网络失败；取消、换网、缺少网络条件或计划未执行完整不能保存。基线、原完整网址及预算只留在进程内。
- 基线优先的原计划复测：启动前再次展示目标、预算与明文 DNS 目标，当前输入框及当前 DNS 变化不静默替换原计划。比较检查版本、完整网址/预算、代理声明、原始 DNS 目标和可见网络条件；系统 DNS 改变明确标注，观察变化不宣告因果修复。
- 增加 `NETWORK_DEEP_COMPARISON`，将基线、本次报告和比较条件一起导出。冻结载荷、唯一请求码、旋转及旧回调隔离沿用单报告导出规则。
- 增加基于事件的说明：HTTP 代理下没有本地站点 DNS 回调、常见 fake-IP 范围、AAAA NOERROR 空回答、UDP/TCP 地址集合不同、首次失败而复核成功。说明与原始观察分别保留，不据此生成泄露或污染结论。
- 新增“代理只读协同”：用户提供 HTTPS 控制 API origin 和可选 Secret 后，固定读取版本及连接快照，显示逐项请求结果与失败原因，可导出脱敏快照。
- 专业、深度和协同报告增加 `EvidenceEnvelope` 共享来源外壳；保留原报告种类和结构。应用版本统一由 `AppIdentity` 读取 `BuildConfig.VERSION_NAME`，修复旧专业报告写死 0.5.0 的元数据缺陷。
- 修复本机自检的取消竞态：等待服务端接收连接时，取消会直接唤醒等待并检查终态，不再等原实验预算耗尽。新增受控回归保持2秒退出要求。
- 设备仪器启动由无界 `startActivitySync` 改为活动监视器8秒等待，超时明确失败；已编译测试APK，真实手机复核仍待执行。

## 代理协同的实际范围

只请求 `GET /version` 与 `GET /connections`，每项最多 3 秒、总预算 15 秒、每响应最多 256 KiB，最多保留 100 条连接和每条 16 个链名。输入必须是无账号、路径、查询和片段的 HTTPS origin；使用默认平台 TLS 和系统代理选择，关闭跳转、Cookie 和自动重发，不保留响应原文或响应头。

**当前不支持普通 HTTP 控制 API，包括常见的本机 HTTP 控制口。** HTTP/SOCKS 流量代理入口也不是控制 API。没有受信任证书的 HTTPS 控制 API 时，继续使用网站/DNS 诊断；本版不会自动开启控制服务、配置 TLS 入口、安装 CA、降低校验或扫描端口。

连接快照来自用户声明的接口，可能包含其他应用活动；TLS 验证仅确认填写地址的服务器身份。当前没有将快照中的连接按请求、目标和时间自动关联到本应用网站实验，`crossSourceCorrelation` 保持 `NOT_ESTABLISHED`。接口能访问与代理路径已验证分别表达。共享 Secret 可能拥有服务端写权限，本应用只使用固定两项读取，不调用测速、配置写入和断开连接接口。

界面展示已筛选的连接字段，App 只提供脱敏快照导出；Secret 不进入报告或设置。打开协同界面不会联网，不自动发现、轮询或订阅日志。与专业及深度诊断互斥，未释放资源时不启动新的实验。

## 保留边界与后续工作

业务权限维持普通网络访问与网络状态读取；没有增加 VpnService、root、Shizuku、其他应用私有数据访问、后台遥测或配置自动写入。深度与专业基线仍分开，不支持持久历史或导入旧 JSON 恢复计划。完整深度导出仍省略 URL 路径/查询及网站正文。

自适应实验选择、完整统一事件流、代理连接自动关联、完整 DNS 泄露路径取证、强制地址族、独立 DoH/DoT、HTTP/3、WebSocket 和完整 ChatGPT 业务测试尚未完成。当前优先让现有观察、比较条件和下一步实验清晰可核对，再扩充观测能力。
