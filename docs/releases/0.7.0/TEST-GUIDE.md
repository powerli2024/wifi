# 0.7.0 真机验收与填写建议

> 类型：版本操作指南；状态：Active；范围：0.7.0 已实现交互和待验证场景；维护：项目维护者；核对：2026-10-23。
> [文档导航](../../README.md) · [当前验证](../../testing/CURRENT-STATUS.md) · [实现评审](REVIEW.md)。

本指南是操作与记录清单，不表示各项已经通过。继续跳过模拟器；手机或代理 API 的实际检查分别记录。先核对安装版本为 0.7.0，并保留待测代理和网络状态。

## 第一次使用：一条网址即可

进入“开始网站与网络诊断”，先选择“仅检查本机环境（不访问外网）”。确认后应取得 Android 可见网络画像和正常响应/受控超时/受控拒连三项结果。展开“手机内置实验”查看细节；成功识别预定超时属于本机场景符合预期，不表示外部网站超时正常。

再使用默认 ChatGPT 网址或输入出现问题的完整 HTTPS 网址，选择你知道的代理状态后开始自动诊断。先读顶部主要定位，再读 DNS / 连接 / TLS / HTTP / 正文阶段表。多次尝试保留首轮结果，展开网站证据查看复核；HTTP 403/429 可与 TLS 成功同时存在。

扩展 DNS 默认关闭。启用后自动使用确认时当前网络的第一个数字 DNS，查询目标域名的 A/AAAA × UDP/TCP。它会发明文 DNS，与系统 Private DNS 并非同一路操作；数字 IP 网址不适用域名对照。没有当前可用 DNS 时先执行基础诊断，不随意填公共解析器。

顶部工具栏可直接导出已完成报告，长证据之前也有导出按钮。默认脱敏；需要本地深入分析时才选择完整报告。完整网站报告仍省略 URL 路径、查询参数及正文内容。

## 改动前后怎样比较

1. 在改动之前完成一次诊断，点击“保存本次为基线”并确认。确定的连接/TLS/DNS 失败也可作为基线；若按钮不可用，先看缺测、换网或网络画像等具体原因。
2. 保存需要留档的报告。基线与完整计划只保留在应用进程中，关闭进程后不能依靠导出的 JSON 恢复该计划。
3. 修改一个你要验证的设置，记录修改位置与前后值；应用不会替你修改系统 DNS 或代理核心配置。
4. 返回点击“按基线原计划复测”。检查确认窗口中的原网址、预算、代理声明和 DNS 目标，然后开始。
5. 看“与基线比较”及展开的比较条件/变化，再导出“基线与本次对照 JSON”。不同版本、计划、原始 DNS 目标或主要网络条件可能阻断同计划比较；两份报告仍可保存。

**原计划复测会保留原始 DNS 数字目标。** 更换系统 DNS 后，基线中的 raw DNS 不会自动换成新服务器，这让对照目标保持一致。若要检查新配置的 DNS，应另开新的自动诊断计划并明确当前目标；不能把新目标的结果当作原目标的直接改善。系统 DNS 变更可列出观察变化，但时间、缓存、节点和服务端也可能改变，不能仅凭一对样本宣告修复因果成立。

## 可选：代理只读协同怎么填

在“代理只读协同”填代理软件提供的 **HTTPS 控制 API 来源地址**，例如格式 `https://controller.example:9090`，此示例不能直接用于检测。填写来源地址即可，不加 `/version`、`/connections` 或查询参数；Secret 按实际控制 API 设置填写，未设置认证时留空。

当前只支持正常平台证书验证的 HTTPS。普通 `http://127.0.0.1:9090` 控制口不支持；HTTP/SOCKS 代理监听端口也不是控制 API。没有合适接口可跳过此可选项，继续网站和 DNS 诊断。不要为了通过测试关闭证书校验或把无关代理端口填作 API。

确认窗口列明固定两项 GET、每项 3 秒/总 15 秒、每响应 256 KiB/最多 100 条连接。打开页面和填表不会发请求；确认才读取。Secret 只用于本次请求，不写入报告或设置；共享 Secret 可能在服务端拥有其他权限，本应用只调用读取接口。

| 结果 | 优先核对 |
|---|---|
| 收到版本和连接快照 | 核对是否为预期控制服务；连接属于采集时刻，尚未关联到本应用网站请求 |
| HTTP 401 | Secret 是否正确，认证是否属于该接口 |
| HTTP 403 | 控制 API 的访问权限与访问来源策略 |
| HTTP 404 | 是否填到了网站/流量代理端口，服务是否支持固定 API 路径 |
| TLS 证书或主机名失败 | 填写域名、设备时间与服务证书；保持正常校验 |
| 超时/连接失败 | 地址、监听与实际网络路径；重试前保留原结果 |
| 非 JSON/缺字段/重复 ID/超限 | API 兼容性和响应形状；不将不完整快照当作成功关联 |

界面可查看筛选后的连接元数据，导出仅提供脱敏快照；没有配置写入、测速或关闭连接动作。连接列表可能包含其他应用，不能凭列表有某个域名断言本应用请求经过该代理。API 快照与网站运行是独立采集，当前不自动匹配请求 ID、目标和时间。
