# 0.5.0 手机实测指南

> 类型：版本操作指南；状态：Archived；范围：对应版本的历史时点；维护：项目维护者；核对：2026-10-23。
> [文档导航](../../README.md) · [当前验证](../../testing/CURRENT-STATUS.md)。文内反引号文件路径若无说明均相对项目根。

日期：2026-10-22。本轮由用户安装检查，未运行 Android 模拟器。APK 是调试签名试用版；本地测试不代表真实代理、DNS 路径或修复效果已验证。

## 先看这三条

1. **只测本应用**，不接管 VPN。打开界面、选择场景或查看修复建议不会发起主动探测；点击开始并确认计划后才执行。
2. **先观察，再改一项。** 新版重新建立基线，旧 0.3/0.4 报告不可冒充新版同计划对照。配置副本含原凭据，不要当脱敏报告分享。
3. **三种状态不同：副本已核对、用户确认已导入、复测观察改善。** 都不能单独证明全机无 DNS 泄露。

## 建议按这个顺序检查

| 步骤 | 操作 | 预期与反馈重点 |
|---|---|---|
| 1. 交互 | 打开概览、测试、修复；查看离线演示，再返回 | 三个主入口；报告是子页，返回原入口；演示始终明确标注且不能保存为实测基线 |
| 2. 显示 | 切换系统深色模式，调大字体，横屏并打开键盘；有条件用 TalkBack 浏览 | 标签持续可读，错误贴近字段，按钮可触达，无底栏/键盘遮挡；这些视觉和无障碍项需要你实际确认 |
| 3. 最少输入 | 概览点“开始快速检查”，先查看并取消确认，再确认执行 | 默认只有系统解析 example.com、每项一次；取消确认不开始；报告区分地址/错误/未测，不给安全分 |
| 4. 重现初测 | 测试→“DNS 连通对照”，系统与原始域名均 example.com，A、端口53；核对原始目标 | 场景自动填表而不联网。网络 DNS 地址可能是 VPN 虚拟地址；未知时需手动提供获准测试的数字 IP。记录系统诊断码、UDP/TCP响应及局限 |
| 5. 重试 | 专业页明确启用一次附加尝试，确认相同目标与总预算 | 默认关闭；仅超时/明确连接失败才追加。报告详细证据保留每次尝试及标记，后次成功不能抹掉首次失败。不能稳定制造失败时此项记未验证 |
| 6. 配置练习 | 修复→“审查配置与保存副本”，先用 fixtures/mihomo-dns-example.yaml 演练，再处理自己的完整配置 | 必须主动选 DNS 方案；生成可读差异；只保存新文件。示例没有代理节点，不能替换日常配置 |
| 7. 保存核对 | 选择可信的本地文档提供者，保存副本 | 展示预期/读回摘要。已写入未核对、核对失败与已核对分别显示；只有已核对时可记录“我已在客户端导入此副本” |
| 8. 真实复测 | 先保留原配置及覆盖设置；手动导入经核对副本，确认客户端加载；返回按修复基线计划复测 | 测试仍须确认。使用生成时关联基线，基线被替换或清除会阻止误对照；结果只报告观察改善/未变/不可比 |

建议优先完成 1–4，再做配置修改。没有实际异常时无需为了测试而换 DNS。取消正在执行的检查会停止接收证据并清理资源；系统/文件提供者若阻塞，界面应保留忙碌状态，不允许叠加新任务。写入期间取消可能留下部分副本，不应导入。

## 专业字段填写

| 目的 | 填写 | 不要据此推导 |
|---|---|---|
| 系统/原始 DNS 对照 | 同一个有效域名；原始解析器数字 IPv4/IPv6；端口53；先A；按需分别选UDP/TCP | 系统A/AAAA、缓存与原始A并非完全同条件；不同地址不直接等于污染或泄露 |
| 追踪 DNS 路径 | 自己控制的唯一子域名及有效记录；关联权威DNS、代理或网关日志与时间窗口 | 随机域名、1ms响应、Private DNS或VPN标签均不能独立证明线上路径 |
| HTTPS 出口 | 支持本工具 /v1/echo 契约的受控 HTTPS 源地址；独立确认的预期来源IP，可留空 | 不能填普通网站/订阅URL/通用IP页面；不能把本次返回值反填为预期“正确答案” |
| 修改后对照 | 同一新版、同一计划、同一目标/域名/协议/尝试策略；另存基线 | 换域名做唯一标记属于另一实验，不能冒充严格同计划前后对照 |

原始 UDP/TCP 是明文探针，Private DNS 已启用时也不会自动变成 DoH/DoT。确认框会说明这一点；它不会为测试关闭或修改系统 Private DNS。

## 出问题时怎么恢复

修改前自行保存原配置，记下客户端 DNS 覆盖选项与系统 Private DNS 原模式/主机名。应用的进程内原文不是持久备份。断网时仍能查看恢复卡：切回原配置及本次修改前的选项，再确认计划后复测。不要为取得响应而关闭证书验证或取消 VPN 阻断规则。

若文件写入/核对失败，原文件保留；目标可能是不完整文件，重新选择新文件保存。读回匹配仅说明当时该副本的内容一致，不保证后来未被修改、不保证客户端支持，更不代表已生效。

## 建议回传

- 手机型号、Android版本、应用0.5.0、代理客户端/核心版本、Wi‑Fi或移动网络、是否将本工具纳入代理。
- 所走步骤、预期与实际表现；界面问题可附截图，先隐藏域名、IP与文件位置。
- 一份新的**脱敏 JSON**；若做前后实验，导出“基线与本次对照”的脱敏副本。
- 若选择了重试，说明是否出现第二次及是否在取消/切网后仍有新增请求；未实际验证的项写“未验证”。

旧报告 `c9ece9df…` 只能说明当时系统 DNS 报错、UDP/TCP 返回地址、HTTPS 未测；不能由脱敏占位符认定同域，更不能定位根因。详细解释仍见 [原试测解读](../0.4.0/TEST-GUIDE.md)。
