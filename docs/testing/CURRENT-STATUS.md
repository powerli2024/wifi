## 当前实现

构建版本0.7.0/code7，min29/target35。保留专业DNS/严格出口核验、Mihomo配置副本修复、网络画像、本机自检、网站五层诊断与可选DNS四项对照。

本版新增深度报告的默认折叠详情、固定工具栏导出、独立进程内基线、原计划复测和双报告比较；解释HTTP代理承接解析、DIRECT与VPN的区别、fake-IP地址特征、空AAAA和UDP/TCP差异。专业报告与深度报告统一从构建读取版本，新增最小来源外层，原schema语义保留。

代理协同只接受用户明确提供的HTTPS控制API，单次读取GET /version与/connections，保留有界白名单快照，默认脱敏导出。未实现与本应用请求的自动关联，也未写入代理设置。仪器启动改为8秒有界等待；该修复尚未在手机上复核。
