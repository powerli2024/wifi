| 实验 | 取得的事实 | 限定解释 |
|---|---|---|
| Android画像 | 默认网络有蜂窝/VPN，显式HTTP代理 | 不能单独重建核心节点或完整外层路径 |
| 本机回环 | 正常回应、预设超时、拒连均符合预期，服务结束 | 只验证本机受控环境 |

| DNS对照 | A/UDP与TCP均NOERROR同一fake-IP特征地址；AAAA均NOERROR空答案 | 不把保留地址当污染；空答案不直接判泄露 |
| 网站DNS事件 | 无本地站点解析回调，实际选择HTTP代理 | 代理代解析是合理解释；未证明内部真实解析器 |
| TLS负例 | 受控不可信证书被拒绝，一次尝试，HTTP未启动 | 未安装CA/关闭验证；USB回环场景 |
| 取消/导出 | USER_CANCELLED保留部分观察；两种JSON实际保存核对 | 不是对所有文件提供者/后台生命周期的保证 |
