# 安全、隐私与负责任使用

> 类型：安全策略；状态：Active；范围：0.7.0现状或明确标注的目标要求；维护：项目维护者；核对：2026-10-23。
> [文档导航](../README.md) · [当前验证](../testing/CURRENT-STATUS.md)。文内反引号文件路径若无说明均相对项目根。

## 不改变被测代理

没有 VpnService、root、CA 安装、系统代理写入、VPN 准备调用、protected socket、bindProcessToNetwork、底层网络 socket factory 或代理写接口调用。0.7.0 新增用户确认后的代理 API 只读快照，端点限 GET `/version` 与 GET `/connections`。既有 Mihomo DNS 修复副本仍需用户导入客户端并验证，不会静默改动被测代理。系统 DNS 只提供主机名复制及公开设置入口。

## 数据最小化

- 用户主动输入的 HTTPS origin、DNS 域名、数字解析器及预期 IP 仅放在进程内；旋转保留的输入草稿也不持久化。
- 专业链与深度链各保留一个当前报告和一个用户选择的基线；代理协同另保留一个当前快照。均在进程内，UI status为单条消息，不建立持续增长日志。
- 不自动收集设备序列号、广告 ID、账号、Cookie、包清单、通讯录、定位、报文负载或其他应用信息。用户主动选取的 YAML 可能含节点凭据和订阅 URL；原文仅在进程内用于修复，不请求 URL、不上传、不写缓存、不记录异常原文。
- 用户确认的代理协同快照可能含其他应用的连接元数据；仅保留白名单字段，不采集包名/进程字段或原始 JSON，不自动归属于本应用。页面可查看有界明细，当前 UI 仅提供脱敏快照导出。
- 专业回显只接受HTTPS origin，拒绝账号、路径、查询和fragment，固定 `/v1/echo` 并加入随机requestId。网站诊断接受HTTPS路径与查询，拒绝账号和fragment；实际请求会发送所填路径/查询，报告不保存它们，不应输入凭据链接。
- 错误使用固定 errorCode；不展示/导出网络异常原文。
- 完整导出含 IP、域名、网络 ID、配置的 DNS 和 Private DNS 名称；脱敏版隐藏这些标识。脱敏版仍含时间、OS API、传输类型、真假状态、错误类别和地址数量，不承诺绝对匿名。
- 不自动上传或分享。SAF 目标由用户选择；如果选择云盘，其提供方会接收文件，用户必须自行判断。

## 配置修复输入与输出

使用 SnakeYAML 2.7 节点解析和局部原文补丁，禁止任意 Java 对象构造；输入限 UTF-8、256 KiB、单文档，限制深度和节点数量。重复键、锚点、合并、自定义标签等歧义结构不自动修改。重读输出并校验修改范围；未覆盖字段不能当作已修复。

导出使用创建文档流程，只接受 content URI，并拒绝与原始文件相同的 URI/文档 ID。冻结输出绑定随机身份与不复用的请求码；旋转不换内容，进程丢失后不写旧数据。不请求长期 URI 授权。创建文档提供者若恶意违反 Android 契约，不在应用能够完整验证的范围内。写入关闭后读回最多 256 KiB + 1 字节，核对长度/SHA-256 并解析。不可读只记已写入未核对；不一致或超限记失败。用户导入确认不替代运行状态验证。保存失败或写中取消可能留下不完整副本。

文件字节数受限，但第三方文档提供者的阻塞时间由系统决定；工作在单独线程，不无限扩建线程。未完成的文件读取/写入不宣称成功。完整 YAML 含原有敏感字段，不提供伪装成可分享脱敏配置的输出。

## 网络防护

专业回显、网站和代理协同 HTTPS 请求均使用平台默认信任和主机名验证，不跟随重定向。严格回显链另校验JSON内容类型、压缩、大小、重复字段、nonce、IP与UTF-8；普通网站链不套用JSON契约，记录HTTP状态并有界读取正文。

可选原始 DNS 是明确标注的明文 UDP / TCP 实验，不属于 HTTPS。数字目标避免引导解析，默认不启用；没有因 Manifest 禁明文 HTTP 就声称所有 socket 加密。DNS 报文既不能认证解析器，也不能证明没有透明改写。

专业回显与原始DNS响应上限为4KiB。专业HTTPS默认单次预算8秒，受总预算约束；原始 DNS 每项连接与读取共用 8 秒绝对截止。旧模式的证据接收/终态发布预算为 20 秒，启用原始 DNS 为 60 秒。Java/Android 系统操作可能不能立即中断，平台资源释放和运行槽占用可能超过该预算；若仍在释放连接，不开启第二次运行。默认每项一次，明确启用时至多追加一次；固定退避也计入总预算，不改变目标/协议，不用成功覆盖首次失败。超时结果不是 fail-closed 证明。

专业回显的 `Connection: close` 请求服务器关闭连接，避免工具自身连续运行留下可复用的长连接。平台内部行为仍应在真实设备上复核。

取消先冻结证据并提交资源清理，再采集终态网络元数据，避免同步系统快照挡住 socket 关闭。工作线程退出与报告发布完成前均不重新开放槽位。快照自身仍依赖系统调用，不承诺其完成时间。

## 威胁模型局限

- 端点可能伪造来源地址；用户的信任声明不是密码学证明。
- VPN 可能选择性代理本工具，其他应用可能不同。
- NAT、反向代理和共享出口可能产生相同 IP；IP 相等不证明路由相同。
- 网络 callback 和快照有竞态/可见性边界；只记录“观察到变化”，不声称无变化就绝对稳定。
- DNS API 成功、AAAA、Private DNS=true 或 VPN=true 都不证明线上保密。
- 原始 DNS 的有限解析器可能拒绝合法但不支持的报文结构；解析失败不是目标代理漏洞。
- 配置/IP allowlist 错误会造成不匹配，不应自动归咎于代理泄露。

## 使用约束

只测试你拥有或明确获准测试的域名、服务、设备和网络。不扫描第三方地址，不通过此工具收集他人流量。调试 APK 不应直接作为经过完整审计的商用/生产发布版。

## 网站深度诊断的补充范围

网站请求使用OkHttp，正文最多读16KiB、只保留计数。网站单次15秒、总30秒、最多两次；整组60秒、本机自检默认3秒、扩展原始DNS每项4秒。保持默认代理选择，禁自动重定向和库级连接重试；显式复核由工具记录。报告冻结和平台资源退出是不同时间点。两个报告格式和预算不能互相套用。

## 代理只读协同的补充范围（0.7.0）

已实现显式 HTTPS origin 输入、用户确认和两项 GET 白名单；拒绝地址中的凭据、路径、查询及片段。Secret 仅在内存中生成 Authorization，输入框禁止状态保存/自动填充，确认或离开页面时清空；不保存凭据草稿，不导出异常原文、响应头或原始 JSON。允许字段中回显的本次 Secret 也被清洗。共享 Secret 可能具有核心写权限，本工具的端点限制不会降低该密钥在其他客户端中的权限。

每项最多 3 秒、总预算 15 秒、每响应最多读取 256 KiB，最多保留 100 条连接；JSON 深度/节点/字符串均有限制，拒绝重复对象键和连接 ID。禁缓存、重定向、连接重试及 503 协议重试，不调用测速、DNS 查询或写端点。取消有界返回；系统调用仍未退出时保留全局运行槽，不无限新建工作线程。

当前证据包含离线/受控 HTTPS 测试，尚无真实代理控制 API 验证。API 连通、版本和连接字段均是该来源的声明，尚未与本应用请求关联。共同 `evidenceEnvelope` 仅提供最小来源标注，不等于完整事件契约或自适应实验规划已经实现。
